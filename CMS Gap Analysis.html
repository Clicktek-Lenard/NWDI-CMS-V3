Results Imaging / Radiology Findings UI

API POST /api/results/[id]/imaging-encode exists. Need a form for radiologists to enter impression and findings for XRAY / ECG items.

Medium effort

Results Result Validation Button

API PATCH /api/results/[id]/validate transitions ENCODED → VALIDATED. Need a validate/sign-off button in the releasing tab.

Low effort

Results Send Results by Email Button

API POST /api/results/[id]/send-email generates PDF and sends via SMTP. Need an email button in the releasing panel. Requires SMTP env vars configured.

Low effort

Results Branch Sendout Tab

Tab and route exist in the results module. SendoutPanel component is a stub. Need to implement the sendout workflow for cross-branch specimen forwarding.

Medium effort

Queue HL7 Resend Button

API POST /api/transactions/[id]/hl7-resend upserts an msg_queue row to trigger resend. Need a small resend button per transaction row in the edit-queue form.

Low effort

Clinical ICD-10 Code Autocomplete

The SOAP diagnosis field exists but is free-text only. Need a searchable ICD-10 dropdown. Requires an ICD-10 data table or static JSON loaded into the DB.

Medium effort

Clinical Drug / Medication Formulary

Prescription form is free-text. Need a drug formulary table + autocomplete so nurses/doctors can select standardized medications with dosage presets.

Medium effort

Payment Corporate Billing Statement (SOA)

No statement-of-account PDF for companies. Need an SOA generator showing all transactions billed to a company within a date range with totals.

Medium effort

Reports Daily Census / Demographic Report

No report showing patient demographics breakdown (age/gender/type/company) for a given day or period.

Medium effort

Reports Doctor Productivity Report

No per-physician patient count or revenue contribution report. Useful for BM/admin dashboards.

Medium effort

Auth Session Timeout Warning

JWT expires silently after 2 hours. Need a countdown warning with option to extend before expiry. Low complexity — countdown from session issue time.

Low effort

Dashboard Multi-day Trend Charts

Dashboard shows today's snapshot only. Need 7/30-day trend charts for queue volume and revenue. Requires a charting library (recharts or chart.js).

Not Started — Design Decision Required
Appointments

Appointment Booking System

No appointment table exists. Current schedule page reads queue data by physician. Need a proper appointment table + create/cancel/reschedule flow.

Queue

Multi-branch Cross-queue View

Session is single-clinic scoped. Need a multi-clinic session mode or a supervisor view that reads across branches (CEN/SMB/TAR).

Patient

Patient Photo Upload

No API or UI for photo capture or upload. Requires a file storage decision (local vs S3/MinIO) before implementation.

Patient

Duplicate Patient Detection / Merge

No deduplication logic. When the same patient is registered twice under slightly different names, there's no merge tool.

Auth

Password Reset Flow

No forgot-password page or reset email. Needs SMTP + a password_reset_token table or time-limited JWT reset link.

Settings

Workstation Configuration

The [WORKSTATION] role is defined in RBAC but no workstation settings page exists. Relevant for assigning printers, stations, and peripheral config.

Dashboard

Per-physician Productivity Widget

No doctor-level stats on the dashboard. BM users need to see patient count and revenue per physician per day.
