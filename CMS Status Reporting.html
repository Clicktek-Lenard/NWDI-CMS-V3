CMS v3 Architectural Advantages over v1

🔒 Type-Safe API Layer

  • Full TypeScript end-to-end
  • Zod validation on all API inputs
  • Prisma v7 type-safe ORM — no raw SQL
  • Compile-time schema errors caught before deploy

⚡ Real-Time UI

  • TanStack Query v5 — auto-polling & cache
  • Queue auto-refreshes every 15 seconds
  • No page reloads for status changes
  • Zustand global state management

📋 5 PDF Document Types

  • Charge Slip, O.R., DRF, Routing Slip, Lab Result
  • Built with @react-pdf/renderer
  • Real DB data in all PDF types
  • Inline browser preview (no download required)

🌍 Modern Architecture

  • Next.js App Router — collocated API + UI
  • Single codebase, no Blade/Vue split
  • Dark mode built-in (next-themes)
  • Responsive layout — works on tablet/mobile

📋 Accession No. Logic

  • LAB: A–L grouped by doctor + company
  • IMAGING: M–X per unique test, offset-aware
  • Reuse logic for same doctor/company across queues
  • Manual-only trigger (specimen-collected checkpoint)

📊 RBAC Matrix

  • All roles in rbac.ts — single source of truth
  • Branch-level gating ([CEN-BRANCH], [SMB-BRANCH])
  • requireApiAuth() enforced on every route
  • Easy to add new roles without touching middleware
